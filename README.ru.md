# WinRust

**Windows-оболочка на Rust: быстрее и легче стандартной.** Небольшие нативные программы (без .NET, без Electron), которые заменяют части Windows: панель задач, Проводник, поиск файлов, диспетчер задач, а ещё чистильщик диска, карту диска и просмотрщик фото. Один установщик всё ставит, одна кнопка всё убирает.

[English](README.md) | **Русский**

> **Сначала прочитайте.** WinRust отключает поиск Windows, прячет панель задач и может отключить Проводник как оболочку. Exe не подписан, поэтому SmartScreen покажет предупреждение. Перед установкой создаётся точка восстановления, но сначала попробуйте на запасной машине или в виртуалке.

## Установка

1. Скачайте `WinRust.exe` из [последнего релиза](https://github.com/Lemxy/WinRust/releases/latest) (Windows 10/11, x64).
2. Запустите от имени администратора.
3. Отметьте галочками нужные компоненты (по умолчанию отмечены все) и нажмите **Install WinRust**. Они ставятся в правильном порядке; упавший или пропущенный компонент не останавливает остальные, окно покажет, что пошло не так.

Поиск Windows необязателен: в урезанной Windows (например, LTSC-образ без службы Windows Search) этот шаг пропускается с предупреждением, а не ломает установку.

Если UAC просит пароль **другого администратора**, пользовательские настройки (автозапуск, задачи планировщика, профиль PowerShell, права поиска) всё равно записываются тому, кто вошёл в систему, а не введённому администратору. Если установщик не может определить этого пользователя, он останавливается, ничего не изменив.

**Обновление:** скачайте новый `WinRust.exe` со страницы релизов, запустите от имени администратора и нажмите **Update WinRust** («Обновить WinRust» в русском режиме). Установленные плагины обновятся, недостающие поставятся; ваши настройки и сохранённые исходные значения Windows остаются.

Установщик открывается на английском. Кнопка **Русский** в его углу (или «Программы WinRust на English» в меню панели по правому клику) переключает язык всех программ WinRust.

## Удаление

- **Удалить всё** в окне установщика откатывает всё: возвращаются поиск Windows, панель задач, Проводник и службы.
- По одному плагину: `plugin-launcher uninstall <плагин>` (см. [Командная строка](#командная-строка)).
- **Если на экране не осталось панели или рабочего стола:** Ctrl+Alt+Del → Диспетчер задач → Запустить новую задачу → `explorer.exe`, затем откройте установщик и нажмите «Удалить всё».

## Что ставится

| Плагин | Что вы получаете | Что меняется в Windows |
|---|---|---|
| **rust-search** | Поиск файлов по всем NTFS-дискам, Alt+Space | Отключается служба поиска Windows, блокируется SearchHost.exe, прячется строка поиска на панели |
| **rtaskmgr-win32** | Диспетчер задач (Ctrl+Shift+Esc открывает его) | Запуск `taskmgr.exe` перенаправляется на него (системный файл не трогается). Заодно ставится чистильщик диска **rs-du** |
| **topbar** | Нижняя панель в стиле Windows 11: окна, часы, громкость, меню | Стандартная панель задач прячется. Заодно ставятся **reshell** (хоткеи: Win+1/2/3 и Win+\` переключают рабочие столы, Win+D показывает рабочий стол, Win+I открывает Параметры, Win+E файловый менеджер; возвращает панель задач, если topbar упал), **rs-du** и блок в профиле PowerShell (`zoxide`, `grep`=rg, `ll`=eza, `cat`=bat; молчит, если их нет) |
| **rust-explorer** | Файловый менеджер с вкладками и рабочий стол | Папки и диски открываются в нём; **Проводник перестаёт быть оболочкой** (возвращается сам, если topbar не работает). Отключаются PcaSvc, InventorySvc, lfsvc, cbdhsvc, DoSvc ставится вручную, процессы svchost объединяются. Нужен topbar |
| **wiztree** | Карта занятого места на диске («WinRust Disk» в Пуске) | Ничего, кроме файла и ярлыка |
| **photoview** | Быстрый просмотр фото | Добавляется в «Открыть с помощью» (по умолчанию не назначается) |
| **rust-settings** | Параметры на Rust: экран (разрешение, частота, ночной свет, расположение мониторов перетаскиванием), звук (устройства, громкость по приложениям), схема питания, место на дисках и очистка, сетевые адаптеры, Wi-Fi на всех адаптерах (пароль или 802.1X), VPN и прокси, Bluetooth, приложения, Центр обновления, тема, о системе | Ничего, кроме файла и ярлыка. Win+I и меню панели открывают это окно вместо Параметров Windows (лишь несколько редких разделов по-прежнему системные) |
| **debloat** | Отключает телеметрию, Copilot, Recall, рекламу в Пуске, фоновый Edge | Службы и политики реестра; старые значения сохраняются и возвращаются при удалении. **Только из командной строки:** `install debloat --yes` |
| **purge** | Удаляет предустановленный мусор, как Tiny11: Clipchamp, Новости, Погода, Xbox-оверлеи, Teams, Cortana, виджеты, Skype и др., а также задачи телеметрии | **НЕОБРАТИМО, отката нет.** Приложения удаляются для всех пользователей и из образа; Магазин, Параметры, Пуск и среды выполнения остаются. Сначала запустите `purge.exe`: он только показывает список. **Только из командной строки:** `install purge --yes` (OneDrive и Edge: `purge.exe --apply --onedrive --edge`) |
| chrome-rs | Браузер | Пока не ставится |

Все изменения обратимы: удаление возвращает те значения, что были до установки.

## Стили

Правый клик по пустому месту панели → **Стиль панели…** открывает меню **Стиль**. Выбор сразу применяется к панели, файловому менеджеру (rust-explorer) и окну поиска (Alt+Space):

| Стиль | Как выглядит |
|---|---|
| **Обычный** | Синий, как в Windows 11, панель внизу |
| **Терминал** | Зелёный на чёрном, шрифт Consolas, прямые углы |
| **Плавающий док** | Панель-пилюля по центру; развёрнутые окна занимают весь экран, док уезжает из-под них и возвращается у нижнего края |
| **Тайлинг** | Тонкая панель сверху, янтарный акцент, скругления как в Обычном; «Разложить окна плиткой» ставит открытые окна рядом |
| **Белая дорога** | Цвет слоновой кости с золотом: еле заметные треугольники, часть с золотой обводкой, за панелью, её окошками и rust-settings |

Выбор хранится в `%ProgramData%\WinRust\style.txt`.

Там же выбирается подложка панели: **Сплошная панель**, **Полупрозрачная панель** (50%) или **Прозрачная панель** (сквозь неё видны обои; значки, текст и часы остаются чёткими, а на OLED-экранах это ещё и бережёт от выгорания). Прозрачной можно сделать панель в любом стиле. Непрозрачность в процентах хранится в `%ProgramData%\WinRust\bar-opacity.txt`; другое число там (например, `25`) даёт другую степень прозрачности.

## Бенчмарк

Одноразовые замеры на одной машине (Windows 11 IoT Enterprise 10.0.26300, RTX 4060 Laptop, NTFS). Это порядок величин, а не лабораторные цифры.

| Что | Windows | WinRust | Разница |
|---|---|---|---|
| Поиск файла (rust-search по всему C: против `dir /s` по одной папке) | 8 340 мс | 45 мс | быстрее на **99,5%** |
| То же против `Get-ChildItem -Recurse` | 16 200 – 28 600 мс | 45 мс | быстрее на **99,7–99,8%** |
| Открыть окно с папкой (rust-explorer, медиана 5 запусков) | 420 мс | 60 мс | быстрее на **86%** |
| Память оболочки (topbar + rust-explorer + rs-shell + reshell против explorer.exe) | 366 МБ | 46 МБ | меньше на **87%** |
| То же вместе с индексом поиска (53 МБ) | 366 МБ | 99 МБ | меньше на **73%** |
| Размер файлового менеджера | 3 280 КБ | 498 КБ | меньше на **85%** |
| Размер диспетчера задач | 5 791 КБ | 869 КБ | меньше на **85%** |
| CPU панели в простое (topbar после оптимизации, % одного ядра) | 0,00–0,10% (explorer) | 0,05–0,10% | на уровне Проводника |

В сумме: **в 85–99% случаев быстрее или меньше, по CPU в простое равны.** Оговорки: rs ищет по готовому индексу MFT (за это платит 53 МБ памяти), а `dir` и PowerShell обходят диск заново; explorer.exe при замере всё ещё работал и держал окна, поэтому выигрыш по памяти немного завышен; поиск Windows и диспетчер задач не сравнивались.

## Для разработчиков

### Структура
```
src/            установщик (plugin-launcher.exe)
  main.rs         таблица плагинов PLUGINS: имя, тексты, пара install/uninstall, значок
  install/        что каждый плагин меняет в системе и как это откатывается (файл на плагин)
  cli.rs, ui.rs   командная строка и окно; оба вызывают одни и те же функции установки
common/         winrust-common: переключатель языка (t!/tf!), стили и палитры, разбор вывода reg.exe, чтение MFT
plugins/        исходники всех плагинов, каждый отдельный crate
ReShell/        reshell (хоткеи рабочих столов, страховка topbar), ставится вместе с topbar
payload.txt     какие exe вшиваются в установщик и где их кладёт сборка
payload/        эти exe после сборки (не в git)
scripts/        сборка, обновление, релиз
```
Всё собрано в один cargo workspace (один `Cargo.lock`, все exe в `target\release`). `plugins/rust-search` и `plugins/chrome-rs` собираются отдельно: им нужен `panic = "unwind"` (см. `Cargo.toml`).

### Сборка
Нужны Windows x64 и Rust stable (1.85+) с MSVC.
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-all.ps1
```
Результат: `target\release\plugin-launcher.exe`, внутри все плагины. Закройте запущенный установщик перед сборкой. Тесты: `cargo test --workspace` (и `cargo test` в `plugins\rust-search`). CI делает то же самое при каждом пуше (`.github/workflows/build.yml`).

| Скрипт | Что делает |
|---|---|
| `build-all.ps1` | всё: плагины → `payload\` → установщик |
| `build-plugins.ps1` | только плагины → `payload\` (без пересборки установщика) |
| `update-plugin.ps1 <плагин>` | пересобрать и переустановить один установленный плагин без пересборки установщика (просит админа через UAC) |
| `user-mode.ps1`, `dev-update.ps1` | режим разработчика: topbar, rust-explorer, rs-shell и reshell запускаются из `%LOCALAPPDATA%` поверх Проводника и меняются без админа |
| `bench.ps1` | бенчмарк поиска и диспетчера задач |
| `publish.ps1`, `release.ps1` | коммит и пуш; релиз на GitHub с `WinRust.exe` |

### Командная строка
Из терминала **с правами администратора**:
```
plugin-launcher list
plugin-launcher install <плагин>... --yes (одно или несколько имён, либо `all` = то, что ставит окно; без --yes только покажет предупреждения и ничего не изменит)
plugin-launcher update <плагин>          (переустановить из payload\ рядом с exe)
plugin-launcher uninstall <плагин>
plugin-launcher rollback --yes           (удалить всё)
```
Несколько плагинов в одной команде ставятся в порядке таблицы (topbar раньше rust-explorer); упавший не останавливает остальные. Коды выхода: 0 успех, 1 ошибка (хотя бы один плагин не встал), 2 неверные аргументы или нет `--yes`. Без аргументов открывается окно. Журнал установки: `%ProgramData%\plugin-launcher\install.log`.

### Новый плагин
1. Crate в `plugins/<имя>`, добавить его в `members` корневого `Cargo.toml`.
2. Строка в `payload.txt`.
3. `src/install/<имя>.rs` с парой install/uninstall (и строка `mod` в `src/install/mod.rs`). Перед любым изменением сохраните исходные значения, чтобы удаление могло их вернуть.
4. Запись в `PLUGINS` (`src/main.rs`). Окно, его высота и командная строка подхватят её сами.
