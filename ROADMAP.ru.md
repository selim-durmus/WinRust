# WinRust: планы

(English version: [ROADMAP.md](ROADMAP.md))

У каждого пункта указано, насколько он проверен: **тесты** (юнит-тесты), **собрано** (компилируется, не запускалось), **запускалось** (руками на живой системе), **сквозная** (полная установка/удаление на живой системе).

## Сделано

### Установщик
- Исправления после ревью (v0.3.0): rs-du хранит список карантина рядом со своим exe (писать туда может только администратор), `payload\` двумя уровнями выше берётся только из `target\release`, rtaskmgr и rust-explorer сохраняют и возвращают чужие настройки диспетчера задач и папок, rust-search сначала возвращает поиск Windows и только потом удаляет свои файлы, DiagTrack оставлен debloat, один разбор вывода `reg query` с тестом. *тесты, собрано*
- Параметры без Проводника (Win+I и меню панели): Параметры — Store-приложение, оно открывается только при Проводнике в роли оболочки, поэтому скрытый помощник запускает Проводник, ждёт его панель, открывает страницу, выводит окно на передний план (в том числе поверх полноэкранной игры) и возвращает rust-explorer после закрытия Параметров; зависший процесс Параметров сначала убивается. Панель скрывается только для полноэкранных игр и видео. *собрано, проверено вручную*
- Один `plugin-launcher.exe`, в который вшиты все плагины (распаковка в Program Files, не в %TEMP%), статический CRT, тёмное окно на Win32/GDI. *запускалось*
- «Install WinRust» ставит недостающее по порядку (topbar раньше rust-explorer), когда всё стоит, обновляет; «Удалить всё» удаляет в обратном порядке. *собрано*
- Сбой установки откатывает свои изменения (кроме обновления рабочей копии); исходные значения (WSearch, строка поиска, настройки Проводника, службы) сохраняются в `HKLM\SOFTWARE\plugin-launcher\<плагин>` и возвращаются при удалении; несмертельные ошибки пишутся в `%ProgramData%\plugin-launcher\install.log`. *собрано*
- Точка восстановления перед установкой. *собрано*
- Выбор, что ставить (#7): в окне галочка у каждого компонента, в командной строке несколько имён или `all`; упавший или пропущенный компонент не останавливает остальные, ошибки перечисляются в конце. Отсутствие службы Windows Search (урезанные сборки LTSC) для rust-search при установке и удалении теперь предупреждение, а не ошибка. *собрано*
- Пользователь сеанса, а не элевированная учётная запись (#4): если в UAC введён другой администратор, пользовательские настройки (HKCU, задачи планировщика, профиль PowerShell, право на канал rust-search, Run-ключ rs-launcher, HKCU-политики debloat) пишутся владельцу explorer.exe (или topbar / rust-explorer / rs-shell) этого сеанса через `HKU\<SID>`. Если пользователя определить нельзя, установка останавливается до любых записей. Удаление продолжается с предупреждением. *тесты (подмена ключей), собрано*
- Одна кнопка ставит недостающее **и** обновляет установленное: запуск нового `WinRust.exe` доносит исправления до всех плагинов (v0.2.1). *собрано*
- Командная строка: `list | install <плагин>...|all --yes | update <плагин> | uninstall <плагин> | rollback --yes`, коды выхода 0/1/2; окно и командная строка вызывают одни и те же функции. Запускались только команды, которые ничего не меняют. *запускалось (частично)*
- `update` и `scripts\update-plugin.ps1`: переустановка из `payload\` на диске без пересборки установщика. *запускалось*
- Английский по умолчанию, переключатель Русский/English в установщике и в меню панели; выбор хранится в `%ProgramData%\WinRust\lang.txt`. *тесты*
- Устройство кода: один cargo workspace; установщик разделён на `install/` (файл на плагин), `cli.rs`, `ui.rs`; общий crate `winrust-common` (переключатель языка, чтение MFT); один список `payload.txt` для сборки и скриптов; CI на GitHub Actions. *тесты*

### Плагины
- **rust-search**: служба поиска по NTFS + Alt+Space; отключает WSearch, блокирует SearchHost.exe, прячет строку поиска. Правый клик по результату: переименовать, в корзину, «удалить навсегда + почистить реестр» (сканирование → подтверждение → удаление; реестр сначала сохраняется в `%LOCALAPPDATA%\rs-search\registry-backups\*.reg`). *тесты, запускалось*
- **rtaskmgr-win32**: заменяет диспетчер задач через IFEO-Debugger (`taskmgr.exe` не трогается); при панике пишет `%APPDATA%\rtaskmgr\crash.log` и открывает настоящий Taskmgr. *тесты, запускалось*
- **topbar**: нижняя панель в стиле Windows 11 вместо панели задач; `topbar.exe --restore` возвращает панель задач. Вместе с ним ставятся хоткеи reshell, rs-du, блок профиля PowerShell (`src/install/profile.ps1`, Windows PowerShell 5.1 и pwsh 7). *запускалось; блок профиля только на временном профиле*
- **Страховка reshell**: если topbar не запущен, а панель задач скрыта, два раза подряд (~10 с), запускает `topbar.exe --restore`. *тесты; сценарий «убить topbar» не проверялся*
- **Хоткеи reshell**: Win+D (показать рабочий стол) и Win+I (Параметры) работают без Проводника, как Win+E (v0.2.1). *запускалось*
- **Стили** (v0.3.0): шестерёнка в левом краю панели переключает Обычный / Терминал / Плавающий док / Тайлинг; панель, rust-explorer и окно поиска перекрашиваются сразу (широковещательное сообщение, `%ProgramData%\WinRust\style.txt`). Док не занимает места на экране и уезжает из-под развёрнутых окон; Тайлинг ставит панель наверх и умеет раскладывать окна плиткой. *запускалось*
- **Вид topbar** (v0.3.0): значок сети рисуется сам (дуги Wi‑Fi по сигналу, крестик без сети, «!» без интернета, по данным Windows о подключении); новая панель Wi‑Fi (статус, карточка подключённой сети с отдельной кнопкой «Отключиться», сохранённые и открытые сети, строки появляются по очереди); меню только из текста с подсказками клавиш; выбор языка ввода (левый клик по ENG/RUS); трей проявляется с анимацией, стрелка поворачивается. *запускалось*
- **rust-explorer**: файловый менеджер (вкладки, иконки, копирование/вставка/удаление через IFileOperation, контекстное меню, перетаскивание), рисует рабочий стол, отключает Проводник как оболочку через `rs-shell --overlay` (не позже 90 с после входа: Windows 26300 больше не пишет отметки автозагрузки, которых он ждал, v0.2.1), урезает службы. *тесты, запускалось*
- **rust-explorer, быстрый, в духе File Pilot**: папки читаются в фоновом потоке через `FindFirstFileExW` (large fetch) и обновляются, когда меняются на диске (выделение и прокрутка сохраняются); строка фильтра внизу фильтрует по мере набора (набор в списке, Ctrl+F; стрелки двигают выделение, Enter открывает, Esc очищает, понимает другую раскладку); «Подпапки» (Ctrl+E) обходят дерево в несколько потоков в индекс в памяти и ищут по нему на каждую клавишу (весь C:, 1,3 млн записей: обход 11 с, результаты появляются по ходу, около 30 мс на запрос); боковая панель с недавними, закладками (Ctrl+D, звёздочка), дисками и папками, разделы сворачиваются, системные значки; при запуске возвращаются последние вкладки; страница настроек (шестерёнка, Ctrl+,) с переключателями в `%APPDATA%\rust-explorer`. *тесты, запускалось (фильтр, подпапки, настройки, возврат вкладок проверены на экране); индекс подпапок не следит за изменениями на диске (обходится заново через минуту)*
- **rust-explorer, масштаб и размеры папок**: Ctrl+колесо (или Ctrl+Плюс / Минус, Ctrl+0) переключает виды как в File Pilot: «Таблица» (компактные строки постоянной высоты), «Дерево» (папки раскрываются на месте стрелкой, клавиши Вправо / Влево), «Список», затем картинки, растущие мелкими шагами от средних через крупные до огромных значков, с плавным переходом между размерами; каждая вторая строка подсвечена; пустой результат показывается на чистой странице; ничего не перечитывается: картинки (thumbs.rs) берутся у оболочки один раз в 64 / 128 / 256 px, хранятся как растры GDI+ на собственных пикселях и рисуются с масштабом, оба вида рисуются вручную; боковые кнопки мыши и клавиши «Назад» / «Вперёд» клавиатуры ходят по истории; колесо плавно прокручивает список и боковую панель; столбцы «Папки» / «Файлы» / «Размер» считают содержимое каждой папки в фоне (sizes.rs, четыре потока, хранится две минуты, не на сетевых дисках; настройка); адресная строка отпускает фокус при щелчке в другом месте; столбцы всегда заполняют ширину. *тесты, запускалось (масштаб, высота строк, размеры папок, адресная строка проверены на экране); сам список по-прежнему прокручивается строками (стандартный список Windows): попиксельная прокрутка требует своего списка, это следующий шаг*
- **rust-explorer, спокойнее окно**: без системного заголовка: вкладки (со значком своей папки и тонкими разделителями), «+» и кнопки свернуть / развернуть / закрыть в одном верхнем ряду, пустое место которого перетаскивает окно; фильтр плавает над левым нижним углом списка, рядом только значок «Подпапки»; в правом нижнем углу числа, вид и масштаб в процентах, а при масштабировании или по щелчку появляется ползунок (Таблица, Дерево, Список, M / L / XL значки); кнопка вида, нижняя полоса и лишние подписи убраны; имена мельче; не больше пяти недавних мест. Исправлено: строки прыгали вверх-вниз при прокрутке (принудительное скрытие горизонтальной полосы спорило со списком; теперь столбцы оставляют несколько пикселей). *тесты, запускалось (заголовок, вкладки, плавающие полосы, ползунок, полосы прокрутки проверены на экране)*
- **rust-explorer, своё контекстное меню** (menu.rs): пункты оболочки для выбранных файлов (пункты программ, «Отправить», «Открыть с помощью») читаются из меню, которое заполняет оболочка, и показываются в маленьком тёмном окне с полем поиска сверху, которое находит и пункты подменю; «Предоставить доступ», «Восстановить прежнюю версию», «Добавить в библиотеку» и «Копировать как путь» убраны; подсказки клавиш справа; подменю открываются при наведении или клавишей Вправо; меню папки и боковой панели используют то же окно. Также: плавная прокрутка колесом больше не качается на строку вверх-вниз без конца, когда остаётся ровно полстроки; крестик закрытия вкладки меньше. *тесты, запускалось (меню, значки, поиск и закрытие проверены на экране); пункты, которые расширение рисует само без текста (NordVPN Meshnet), пока не показываются*
- **rust-explorer, перетаскивание и мелкие исправления**: при перетаскивании папка под указателем подсвечивается, а отпускание перемещает файлы в неё (копирует на другой диск или с Ctrl; туда, где они уже лежат, ничего не делает); меню не выходит за окно и открывается вверх, если внизу нет места; щелчок мимо открытого меню закрывает его и всё равно срабатывает (правый щелчок по другому файлу открывает его меню); «Закрепить в Пуске» / «Закрепить на панели» в меню идут в панель (новые `topbar --pin-bar` и запрос WM_COPYDATA), закрепления Windows и «Быстрый доступ» убраны, у папок есть «Закладка»; две пустые строки после последней оставляют место для правого щелчка по самой папке; при переходе вверх или назад выделена папка, из которой вышли; плавающие полосы тоньше; больше нет пустого кадра «Папка пуста» (строки меняются с выключенной отрисовкой, и нет перезагрузки после меню или перетаскивания: изменения приносит наблюдение за папкой). *тесты, запускалось (меню, выделение папки, пустые строки проверены на экране); перетаскивание в папку вручную не проверялось; для «Закрепить на панели» нужно обновить topbar*
- **rust-explorer, боковая панель деревом и чистка меню**: боковая панель стала деревом (в папке пользователя лежат Рабочий стол, Загрузки ...; диски и закладки раскрываются так же; стрелка раскрывает папку на месте, какие раскрыты, запоминается); Delete на пункте меню скрывает его во всех меню (Настройки > «Показать скрытые пункты меню» возвращает), а «Стать владельцем», «Отправить» и «Добавить в избранное» убраны; новая папка или файл сразу выделены и открыты для ввода имени (у файла без расширения), поле переименования стоит над именем в цветах списка; если задержать перетаскивание над другой вкладкой, она открывается, а отпускание на вкладке перемещает в её папку; ползунок масштаба, открытый из угла, держится до щелчка в любом другом месте; кнопки в настройках реагируют только на себя. *тесты, запускалось (дерево, скрытие пунктов, переименование новой папки, ползунок, настройки проверены на экране); задержка перетаскивания над вкладкой вручную не проверялась*
- **rust-explorer, тоньше верх и короче боковая панель**: в «Местах» только Рабочий стол, Загрузки, Документы, Изображения и Корзина (её открывает оболочка); кнопка поиска убрана с панели (фильтр внизу, Ctrl+F); строка вкладок и панель инструментов тоньше, значки меньше; подсказки клавиш в меню мельче; в поиске меню Ctrl+Backspace / Ctrl+Delete удаляют слово, Ctrl+A выделяет всё (больше никаких квадратиков). *тесты, запускалось (проверено на экране)*
- **rust-explorer, боковая панель рядом с вкладками**: боковая панель идёт на всю высоту, её верх входит в строку заголовка, там кнопка, которая её скрывает; вкладки и панель инструментов начинаются справа от панели, а при скрытой панели её кнопка стоит первой в строке вкладок (запоминается как `side_pane`). *тесты, запускалось (оба состояния проверены на экране)*
- **rust-explorer, рамка выделения, Ctrl+Z и привычные клавиши**: перетаскивание откуда угодно, кроме имени (рядом с ним, в другом столбце, под строками), рисует рамку выделения с прокруткой у краёв (Ctrl / Shift добавляют к выделенному), а перетаскивание имени по-прежнему переносит файл; Ctrl+Z отменяет последнее удаление (возврат из Корзины), перемещение, копирование, переименование или новый элемент, и из верхней строки меню папки, пока есть что отменять; Ctrl+A, Esc, Shift+Delete (насовсем, оболочка спрашивает), Ctrl+Shift+C (пути текстом), Ctrl+R, Ctrl+1..9 и Ctrl+Shift+Tab для вкладок; «Удалить» в меню идёт тем же отменяемым путём. *тесты, запускалось (рамка, Ctrl+A, отмена удаления / переименования / новой папки / копирования проверены на экране); отмена перемещения вручную не проверялась; повтора (redo) пока нет*
- **Только английский**: русский интерфейс убран из всех программ (кнопка «Русский» в установщике, пункт «WinRust apps in Русский» в меню панели, переключатель `t!`/`tf!`/`en!` в winrust-common; тесты теперь ждут английский). Исправление раскладки в поиске (набрано не в той раскладке) осталось. rust-explorer: без боковой метки у выделенных строк (список и боковая панель), строки плотнее, правый щелчок в боковой панели даёт «Развернуть всё» / «Свернуть всё». *тесты, запускалось (меню панели и строки проверены на экране)*
- **rust-explorer, плавный список, этап A** (предпросмотр, Настройки > «Smooth list» или `RX_NEWLIST=1`): вид «Подробно» рисуется на GPU (Direct2D / DirectWrite на flip-цепочке), кадры идут в такт композитору, пока что-то движется, и не идут в покое, прокрутка попиксельная с плавным торможением, разметка текста и значки кэшируются; щелчки, Ctrl / Shift, стрелки, Enter, контекстное меню, полоса прокрутки и сортировка по заголовкам работают, остальное пока через старый список. `RX_FPS=1` пишет время кадров. Замер на System32 одним и тем же колёсиком: старый список 65 кадров/с скачками по 35 px (строка), новый 120 кадров/с (каждый кадр через 8,3 мс) шагами по 9 px. *тесты, запускалось (замерено, проверено на экране)*
- **rs-du**: чистильщик диска (анализ MFT, кеши, `target`/`node_modules`, корзина, карантин на 30 дней), запускается из меню панели. *тесты*
- **wiztree**: карта занятого места по MFT. *тесты (только раскладка); на живом диске не запускался*
- **photoview**: просмотр фото на WIC, поворот по EXIF, пункт «Открыть с помощью». *запускалось; EXIF-ориентации 5 и 7 не проверялись*
- **debloat**: службы и политики (телеметрия, Copilot, Recall, реклама, фоновый Edge), старые значения в `%ProgramData%\winrust-debloat\undo.txt`, `--undo`. *сухой прогон запускался; `--apply`/`--undo` нет*

## Известные ограничения
- Системные компоненты отключаются или обходятся (обратимо), а не удаляются: удаление `taskmgr.exe` или поиска Windows сломало бы защиту системы.
- Нужны права администратора.
- Win+S и «Пуск» по-прежнему открывают поиск Windows.
